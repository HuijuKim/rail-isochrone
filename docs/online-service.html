구글 지도 API

API쓰는 곳월 무료넘으면 1,000건당
Maps JavaScript (Dynamic Maps)지도. 페이지를 열 때마다 1건10,000$7.00
Places API (New) 자동완성장소 검색. 입력을 멈출 때마다 1건10,000$2.83
Place Details Essentials고른 장소의 좌표. 고를 때마다 1건10,000$5.00
Places Aggregate범위 안 장소 수. 고리 하나에 1건5,000$10.00

자동완성은 세션 토큰으로 묶어 좌표 요청으로 끝내면 13번째부터 무료입니다. 무료 한도는 결제 계정 기준, API 마다 따로 셉니다.

키

  • 브라우저 키(config.json 의 google_maps_api_key): 웹사이트 제한. 로컬 5173·5174 를 허용해 둠. 올릴 때 https://도메인/* 추가. 화면이 더는 Aggregate 를 부르지 않으니 허용 API 에서 Places Aggregate 는 빼기.
  • 서버 키(google_server_api_key 또는 환경 변수 GOOGLE_SERVER_API_KEY): 아직 없음. Places Aggregate 만 허용, 서버 IP 로 제한. 없으면 장소 수 칸이 숨습니다.
  • API 마다 하루 할당량 상한과 결제 알림을 걸어 둘 것. 장소 수 한도는 src/placecount.py 맨 위 PER_IP_HOUR, PER_DAY 에서 바꿉니다.

알아봤지만 안 쓰는 것

  • Routes API 대중교통: 일본에서 빈 응답이나 도보만 오는 결과가 난다는 보고(2026-09-05). 우리 추정과 비교하는 데 못 씀.
  • Isochrones API: 미리보기 단계이고 자동차·이륜·자전거·도보뿐, 대중교통 없음.
  • TransitLayer: 일본에서 노선이 공식 색으로 나오지만, 노선별로 고르거나 색을 바꾸거나 좌표를 받을 수 없어 우리 노선 그리기를 대신 못 함. 배경 켜고 끄기로는 쓸 수 있음. 다크 스타일은 대중교통 선을 한 색으로 칠함.
  • Map Tiles API: 렌더러를 하나로 합칠 수 있지만 지금 두 갈래가 잘 돌아 얻는 게 적음.
  • google.maps.Marker 는 2024-02 부터 권장 안 함(중단 일정은 없음). 새 마커로 옮기려면 Map ID 가 필요하고 지금의 스타일 설정이 안 먹음.

다시 시작할 때

앞 단계가 뒤 단계의 전제라 순서대로 합니다.

  1. 서버 키 만들기.

    Places Aggregate 만 허용. C:\Users\Huiju\rail-isochrone\config.json 에 google_server_api_key 로 넣고 5174 에서 장소 수를 끝까지 세 봅니다(키가 없는 지금은 “서버 키가 없습니다” 로 거절, 브라우저 키로 부르면 구글이 Referer 가 비었다고 거절하는 것까지 확인함).

  2. master 에 합치기.

    5173 은 index.html 을 요청마다 읽어서 합치는 순간 화면만 새 코드로 바뀝니다. 조합 빌드가 없을 때(/api/combo/status) 합치고 바로 5173 을 다시 띄웁니다.

  3. 호스트와 도메인 고르기.

    Oracle Always Free(ARM 2코어·12GB) 또는 메모리 4GB VPS.

  4. 서버 설치.

    리눅스, Python 3.13 가상환경, pip install -r requirements.txt. 전국 권역을 data/regions/national 로 올림(walk/mm 빼고 약 1.6GB). waitress 를 systemd 로 띄우고(TRUST_PROXY=1, 키는 환경 변수), 앞에 nginx(HTTPS, 요청 속도 제한). 윈도우에서 만든 npz·npy 는 그대로 읽힙니다.

  5. 구글 키 정리.

    브라우저 키에 도메인 추가, 서버 키를 서버 IP 로 제한, 할당량·결제 알림.

  6. 공개 전 확인.

    公共交通オープンデータセンター 자료를 공개 서비스에 써도 되는지(일부는 개발자 한정), 동시 접속 부하 시험.

로컬 시험 서버 5174

운영과 같은 입구로 전국판만 띄웁니다. 5173 과 따로 돌고, 구글 키는 원래 폴더의 config.json 에서 읽습니다(키를 화면에 찍지 않음). PowerShell:

$cfg = Get-Content C:\Users\Huiju\rail-isochrone\config.json -Raw | ConvertFrom-Json
$env:GOOGLE_MAPS_API_KEY = $cfg.google_maps_api_key
$env:GOOGLE_SERVER_API_KEY = $cfg.google_server_api_key   # 없으면 비어 있어도 됨
$env:REGIONS_DIR = "C:/Users/Huiju/rail-isochrone/data/national/regions"
cd C:\Users\Huiju\rail-isochrone-national\src
waitress-serve --host=127.0.0.1 --port=5174 --threads=8 wsgi:app

브라우저 키의 웹사이트 제한에 http://127.0.0.1:5174/* 가 있어야 5174 에서 구글 지도가 뜹니다.

확인 안 한 것

  • fine_* 를 뺐을 때 서버가 거친 도보 경로선으로 떨어지는지.
  • raw/ 가운데 서버가 실제로 읽는 파일(노선·현 경계 등)만 추리면 얼마인지.
  • 公共交通オープンデータセンター 약관의 공개 서비스 조건.
  • 동시에 몇 명까지 버티는지. waitress 는 한 프로세스라 파이썬 계산은 사실상 한 코어씩 돕니다.
  • 유료 VPS 가격.
